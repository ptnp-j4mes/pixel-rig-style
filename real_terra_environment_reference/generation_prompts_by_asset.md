# Real Terra | Per-Asset 3D Modeling and Text-to-3D Prompts

All requests below are visual reconstructions from one screenshot, not original game geometry. Mesh dimensions are practical estimates.

**Global asset export standard:** right-handed Y-up or Z-up configurable, meter scale, mesh origin on local center/bottom where applicable, clean normals, UVs, separate PBR materials, no pre-baked cast shadows, real back faces (360-degree completeness), GLB/FBX compatible, no text overlays or image-plane fakes.

**Global negative guidance:** no perfect mirrored symmetry, no featureless single-color meshes, no hyperreal modern elements, no plastic-looking foliage, no flat cardboard near-camera walls, no hard seams between dirt and grass, no overbright saturated primary blue roofs, no duplicate roof silhouettes across the whole town.
