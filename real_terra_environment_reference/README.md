# Real Terra Environment Reference Kit

Extracted from the user-provided single screenshot (1200x560px).

- `generation_prompts_by_asset.md` — 77 standalone English prompts for manual modeling or a text-to-3D tool.
- `reference_asset_bible.md` — composition, model specifications, detailed construction techniques, lighting, palette, and production plan.
- `asset_manifest.json` — 77 individually addressable asset definitions, 22 material definitions, screen reference ROIs.
- `asset_register.csv` — asset details for bulk import into a spreadsheet or a 3D production board.
- `color_material_palette.csv` — material roughness and approximate art-direction RGB hex values.

**Please note**: The original image was not mechanically converted into 3D assets. The manifest is an informed visual decomposition and modeling guide; sizes, hidden details and true material albedos are estimates. To get high fidelity, first block out the camera and major forms, then compare rendered views against screenshot.
